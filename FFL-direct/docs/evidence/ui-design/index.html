FFL Driver0.3.1-dev

Настоящий APK, Android11/API30,360×800dp и320×640dp. Синтетические UI-данные; это не Preview и не доказательство SQL. Реальная MariaDB проверена отдельными тестами без публикации реквизитов. Последний снимок получен обычным APK после клика системного уведомления, без активной instrumentation; в БД используются только зарезервированные вымышленные заказы. На снимках редактора успех задан синтетическим сценарием; реальные check/save подтверждены отдельно.
