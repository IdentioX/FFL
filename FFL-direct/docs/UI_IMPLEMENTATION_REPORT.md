## Сортировка и обновление

Ручка доступна только при включённом режиме. Long-press и перенос вызывают прежний move(section,id,delta); соседние строки анимируются, переносимая строка поднимается. Модель проверяет границы исходной секции. Сохранение использует прежние driver/date/section preferences, без UPDATE sort_r. Внутренний cache порядка обновляется сразу, чтобы сетевой ответ не отменял недавно выполненное перемещение.

refresh больше не очищает хороший список в начале и не отменяет предыдущий идентичный запрос. Один активный read — один запуск; кнопка вращается и блокируется. Успешный ответ сверяет сохранённые IDs с текущими и обновляет все счётчики. Обычная ошибка оставляет данные с предупреждением; DriverDisabled/SessionRequired очищают их. Дата, локальный порядок и LazyListState сохраняются. После background сначала применяется существующая проверка сессии; сохранённый список не считается разрешением доступа.

Directory и details поддерживают контекстное обновление с аналогичным сохранением хороших данных при обычной сетевой ошибке. Настройки не имеют бессмысленного refresh. Разделы больше не вкладки; для объединённой прокрутки используется новый локальный ключ-1, старые0..2 сохранены.

## Отличия, обусловленные платформой и контрактом

- Редактор БД добавляет CA PEM и фиксирует TLS во включённом состоянии; в упрощённом макете эти требования не показаны. На320dp со шрифтом1.6 подписи панели переносятся на несколько строк.
- Android status bar/keyboard/system navigation настоящие; iOS notch/клавиатура из картинки не имитируются.
- Не добавлены inactive-водители в разрешённый список входа, выдуманная категория менеджеров и неработающий звук. Реальный контракт сохранён.
- Фоновая проверка — existing second-route polling, не push и не автообновление открытых заказов.
- Длинные данные/увеличенный шрифт могут увеличить строку и требуют прокрутки. История до5водителей доступна через раскрытие, контакты и исходный комментарий не удалены ради высоты макета.
- Существующий formatter даты использует отдельную форму месяца (например, «31 декабрь»); это остаётся видимым отличием локализации.
- Точное совпадение текста, дат и количества записей макета не требуется: это реальные значения data layer или явно вымышленные test fixtures. Системный Roboto может отличаться от неизвестного шрифта иллюстрации.

Общий Direct DB account по-прежнему не обеспечивает серверную изоляцию водителей. UI-редизайн не повышает приложение до DRIVER_ROLLOUT_READY; production не используется.
